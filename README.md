# Hypertext Marker

Hypertext Marker is a library for parsing "github flavored common markdown" into HTML this library will be the base
of my statically generated blog project, it's currently under development and does not work yet.

## Input

Hypertext Marker doesn't have a CLI it's a library only hence the input to the lexer/parser is a raw string passed by
the user.

## Build

To transpile the library into javascript execute `$ npm run build`

## Tests

To execute the tests with `vitest` run `$ npm run test`
